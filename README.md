# BIS-Lab-2026 (23CS5BSBIS)

A collection of Jupyter Notebook–based laboratory exercises and experiments for the BIS Lab 2026 coursework.

## Overview

This repository contains practical notebooks covering laboratory topics and workflows for the 2026 academic session. The notebooks include runnable code, explanations, visualizations, and experimentation examples.

## Getting Started

### Prerequisites

- Python 3.9 or later
- Jupyter Notebook or JupyterLab
- Python packages required by individual notebooks

### Installation

Clone the repository:

```bash
git clone https://github.com/sudhanvasm-cs24/BIS-Lab-2026.git
cd BIS-Lab-2026
```

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

Install Jupyter:

```bash
python -m pip install --upgrade pip
python -m pip install notebook jupyterlab
```

Launch JupyterLab:

```bash
jupyter lab
```

## Usage

Open a notebook with the `.ipynb` extension and run the cells sequentially.

Install any additional packages required by a notebook using:

```bash
python -m pip install package-name
```
